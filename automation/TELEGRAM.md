# 텔레그램 봇 — 스크린샷 보내면 당일 분석 1·2·3위와 ★ 가치마 답장

```
더비온 스크린샷 ──> 텔레그램 봇(개인 대화 또는 단톡방)
                       │  집 PC 가치마 웹이 1초마다 새 메시지를 가져감 (long polling, 열어 둘 포트 없음)
                       ├─ Claude 로 배당·마체중·경마장·경주 번호·마명 읽기
                       ├─ 어느 경주인지 찾기: 캡션 → 화면의 경주 번호·경마장 → 마명 → 출발이 가장 가까운 경주
                       ├─ 당일 입력으로 바로 저장 (출발 전이면 공식 모의 기록, 입력자 tg:이름)
                       └─ 답장: 당일 분석 1·2·3위, ★ 가치마, 경주 화면 링크 (+ 다른 허용 대화에도 알림)
웹에서 당일 입력을 저장해도 같은 요약이 허용 대화로 갑니다 (출발 전 입력일 때만).
```

## 1. 봇 만들기 (휴대폰 텔레그램)

1. `@BotFather` 검색 → `/newbot` → 이름(예: 가치마) → 아이디(예: `gachima_sub_bot`, bot 으로 끝나야 함)
2. 받은 **토큰**(`123456:ABC...`)을 복사. 비밀키라 채팅·저장소에 붙여넣지 마세요.
3. 단톡방에서 쓰려면: BotFather 에서 `/setprivacy` → 봇 선택 → **Disable** (그래야 단톡방 사진을 봇이 봅니다)
   → 그다음 단톡방에 봇을 초대.

## 2. PC 환경변수 (cmd)

```
setx TELEGRAM_BOT_TOKEN "123456:ABC..."
```

웹을 다시 실행한 뒤, 봇과의 개인 대화나 단톡방에서 `/id` 를 보내면 대화 ID가 옵니다
(단톡방은 `-100...` 처럼 음수). 쓸 대화 ID를 쉼표로 넣고 웹을 한 번 더 다시 실행:

```
setx GACHIMA_TELEGRAM_CHATS "123456789,-1001234567890"
```

- 허용 대화에서만 스크린샷을 처리하고, 알림도 허용 대화 전부로 갑니다.
- 링크 주소는 기본 `https://gachima.zipbabstudio.com` (`GACHIMA_PUBLIC_URL`로 변경).
- IntelliJ 로 웹을 돌리면 IntelliJ 를 완전히 껐다 켜야 환경변수가 들어갑니다.
- 관리 화면 **텔레그램** 칸에 "켜짐: 허용 대화 N개" 가 보이면 끝.

## 3. 쓰는 법

- 단승 배당 화면 스크린샷을 그냥 보내면 됩니다 (사진으로 보내도, 파일로 보내도 됨).
- 경주를 정확히 하고 싶으면 **사진 설명(캡션)**에 `서울 7`, `부경 5R`, `제주 3경주 다습` 처럼.
  캡션의 경마장·경주·주로가 가장 우선입니다.
- 캡션에 날짜가 없으면 **오늘** 경주에서 찾습니다. 지난 경주를 시험하려면 `11/15 서울 7` 처럼 날짜를 적으세요.
- **주로 상태는 글로 한 번만**: `다습`, `제주 포화`, `함수율 12`, `부경 8%` 처럼 짧게 보내면 그날 그 경마장 주로로 기억하고
  이후 스크린샷에 적용합니다 (경마장을 안 적으면 오늘 경주가 있는 경마장 전부). 주로가 바뀌면 다시 보내면 됩니다.
  웹을 다시 켜면 잊으니 그때는 다시 보내 주세요.
- 우선순위: 사진 캡션의 주로 → 화면에서 읽은 주로 → 글로 정한 주로 → 그날 마지막 입력 → 건조 (이 경우 답장에 알림)
- 배당을 못 읽은 마번은 출전 취소로 계산합니다 → 답장의 ⚠ 를 확인하고, 잘못됐으면 다시 보내거나 웹에서 고치세요.
- 출발 전 마지막 입력이 공식 기록이라, 잘못 저장돼도 출발 전에 다시 보내면 덮어씁니다.
- 사진 한 장에 10~20원 정도 (Claude API).

### 결과 넣기 (공식 결과 수집 전에 바로 정산)

- 글로: `서울 7 결과 5-2-7` → 5번 1착, 2번 2착, 7번 3착. 숫자는 `5 2 7`, `5,2,7` 도 됩니다.
  - 취소마: `서울 7 결과 5-2-7 취소 4` / 1착 확정 단승 배당: `… 단승 6.2` (없으면 ★ 적중 시 기록 배당으로 정산)
  - 다른 날: `11/15 서울 7 결과 3-2-1`, 1착부터 적기: `제주 2 결과 1착 5 2착 3 3착 8`
- 사진으로: 결과(착순) 화면 스크린샷. 캡션에 `결과` 또는 `서울 7 결과` 를 달면 확실하고, 안 달아도 화면이 결과면 알아봅니다.
- 적은 말 외의 나머지는 '착외', 당일 배당이 없던 말은 '취소'로 둡니다.
- 저장하면 ★ 모의 기록이 바로 정산되고, 1·2·3착과 전날·당일 예상이 어땠는지를 답장합니다.
- 30분마다 도는 결과 수집이 공식 착순·확정 배당을 가져오면 그쪽이 덮어씁니다 (잘못 넣어도 결국 공식으로 바로잡힘).

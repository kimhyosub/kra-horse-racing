경마를 보면서 늘 궁금했던 게 있습니다. "기록을 제대로 모아서 계산하면, 배당판보다 나은 판단을 할 수 있을까?" 가치마는 그 질문을 확인해 보려고 만든 개인 프로젝트입니다. 이 글은 어떻게 만들었는지, 그리고 지금까지 무엇을 알게 됐는지를 정리한 기록입니다. 결론부터 말하면 **"생각보다 훨씬 어렵고, 그래서 기록을 다 공개하기로 했다"**입니다.

![가치마의 전체 흐름. 매일 밤 자동으로 데이터를 받고, 당일 배당은 텔레그램으로 들어옵니다](/guide-img/system-flow.png)

# 1. 데이터: 공공데이터포털의 한국마사회 API

출발점은 [공공데이터포털](https://www.data.go.kr)입니다. 한국마사회가 공개한 API 중 다음을 활용 신청해서 씁니다.

- **경주성적정보** — 착순, 기록, 구간 순위, 마체중, 기수·조교사
- **확정배당율 통합정보** — 단승부터 삼쌍승까지 모든 조합의 확정 배당
- **출전표 상세정보** — 경주 전날 공개되는 출전마, 부담중량, 기수 변경
- **경주 심판 정보** — 진로 방해, 제재 기록

수집기는 Spring Boot 배치로 만들었습니다. 날짜 × 경마장 × API 단위로 원본 JSON을 그대로 저장하고, 하루 호출 한도에 닿으면 깔끔하게 멈췄다가 다음 날 이어서 받습니다. 받은 원본은 CSV로 펼쳐서 분석에 씁니다. 응답 필드 이름을 코드에 고정하지 않고 받은 그대로 칼럼으로 펼쳤더니, 중간에 API 필드가 바뀌어도 수집이 깨지지 않았습니다.

# 2. 전날 예상: 배당 없이 21개 요인

첫 번째 모델은 **배당을 전혀 보지 않는** 모델입니다. 경주 전날 알 수 있는 정보만으로 각 말의 우승 확률을 냅니다.

- 최근 폼(최근 3전 착순), 입상률, 같은 거리대 입상
- 전개 — 지난 경주들의 초반 자리, 막판 200m 속도, 결승선 기준 뒤처진 거리
- 휴식 간격, 첫 출전 여부, 나이·레이팅, 부담중량·등급·거리 변화
- 기수·조교사의 1년 승률, 기수 변경, 장구 변경, 직전 경주 심판 기록

같은 경주의 말끼리 비교하는 조건부 로짓 모형으로 가중치를 학습했고, 학습에 쓰지 않은 2025년 7월 이후 **3,201경주**로 검증했더니 **1위 적중 29.9%, 우승마가 상위 5두 안에 든 비율 80.1%**가 나왔습니다. 무작위(10두 기준 10%)보다는 훨씬 낫지만, 배당판의 인기 1위가 이기는 비율(약 37%)에는 못 미칩니다. 배당이 그만큼 많은 정보를 담고 있다는 뜻입니다.

# 3. 당일 분석: 배당을 출발점으로

그래서 두 번째 모델은 방향을 바꿨습니다. 배당을 무시하는 대신 **배당이 말해 주는 확률을 출발점**으로 두고, 마체중 변화·주로 상태·전날 요인 중 배당이 덜 반영하는 부분만 더합니다. 이 모델이 확률을 제대로 내는지 확인한 그림이 아래입니다.

![모델이 본 확률과 실제 우승 비율. 대각선 위에 거의 그대로 놓입니다](/guide-img/calibration.png)

48%라고 본 말들은 실제로 48% 이겼고, 7%라고 본 말들은 7% 이겼습니다. 확률 자체는 잘 맞습니다. 문제는 **배당이 본 확률(회색 선)도 거의 똑같이 잘 맞는다**는 점입니다. 1위 말의 우승률을 비교해 보면 더 분명합니다.

![가치마 당일 1위와 배당 인기 1위의 우승률. 거의 차이가 없습니다](/guide-img/top1.png)

서울·부경은 인기 1위가 조금 낫고, 제주는 가치마가 조금 낫습니다. 차이는 1%p 안팎입니다. "1위를 더 잘 맞히는 모델"로는 시장을 이길 수 없다는 걸 여기서 받아들였습니다.

# 4. 1·2·3위를 사면 손해, ★ 만 사면?

순위대로 사면 어떻게 되는지도 승식별로 검증했습니다.

![당일 1·2·3위를 그대로 샀을 때 승식별 회수율](/guide-img/pool-roi.png)

모든 승식이 100% 아래입니다. 마권 매출에서 떼는 몫(단승 약 20%, 나머지 약 27%)을 넘지 못한 것입니다. 그래서 가치마는 순위가 아니라 **기대값**으로 고르기로 했습니다. 모델 확률 × 배당이 1.1 이상이고 배당 20배 이하인 말만 ★ 로 표시합니다.

![★ 가치마만 샀을 때의 과거 회수율 (확정 배당 기준)](/guide-img/star-roi.png)

학습에 쓰지 않은 기간 1,219건에서 회수율 119%가 나왔습니다. 반기별로 101~140%로 들쭉날쭉하고, 95% 범위는 102~138%입니다. 솔직히 이 숫자를 그대로 믿지는 않습니다. 이유는 두 가지입니다.

1. **확정 배당으로 계산했습니다.** 실제로는 마감 직전까지 배당이 바뀌기 때문에, 출발 전에 본 배당으로 고르면 결과가 달라집니다.
2. **기준(1.1, 20배)을 정하는 과정에서 이 기간을 봤습니다.** 과거에 잘 맞게 기준을 고르면 미래에는 덜 맞는 경우가 많습니다.

# 5. 그래서 모의 장부를 쌓는 중

그래서 실제 돈을 걸기 전에 **모의 장부**로 다시 확인하고 있습니다. 규칙은 미리 정해 두고 바꾸지 않습니다.

- 출발 전 마지막으로 반영한 배당으로 계산한 ★ 를 단승 1단위로 기록
- 확정 배당으로 정산, 출전 취소는 건수에서 제외
- 결과가 나오거나 출발 시각이 지나면 기록 잠금
- **300건 전에는 결론을 내리지 않음**

![실력이 본전인 방법도 기록이 적으면 운에 따라 크게 흔들립니다](/guide-img/sample-size.png)

300건을 기다리는 이유는 위 그림 하나로 설명됩니다. 실력이 딱 본전인 방법도 50건만 보면 37%에서 173%까지 나옵니다.

# 6. 당일 배당은 텔레그램 스크린샷으로

공공데이터에는 **실시간 배당이 없습니다.** 확정 배당은 경주가 끝난 뒤에야 나옵니다. 그래서 당일 분석의 입력을 어떻게 받을지가 가장 큰 숙제였습니다. 처음에는 웹 화면에 배당을 하나하나 입력했는데, 경마장에서 휴대폰으로 하기에는 너무 번거로웠습니다.

지금은 배당 화면을 캡처해서 **텔레그램 단톡방에 보내면** 끝입니다. 봇이 AI로 사진에서 마번·배당·마체중·주로 상태를 읽고, 어느 경주인지 찾아 당일 분석을 계산한 다음, 1·2·3위와 ★, 총평을 답장합니다. 동시에 모의 장부에도 기록됩니다.

![텔레그램으로 배당 화면을 보내면 돌아오는 답장 (예시 화면)](/guide-img/telegram-example.png)

# 7. 운영: 집 PC 한 대

모든 게 집 PC 한 대에서 돌아갑니다.

- **작업 스케줄러** — 매일 21:40 수집(어제~내일), 경주일 아침에 출전표 한 번 더, 낮에는 30분마다 결과 반영
- **웹** — Spring Boot 2.7 · Java 8 · Thymeleaf · H2. 분석 결과 파일이 바뀌면 1분 안에 자동으로 다시 불러옵니다
- **외부 접속** — Cloudflare 터널로 도메인을 연결해서, 공유기 포트를 열지 않고 밖에서 접속합니다

# 8. 지금까지 배운 것

- **배당은 강하다.** 수많은 사람의 판단이 모인 숫자라, 기록만으로 이기기는 정말 어렵습니다.
- **잘 맞히는 것과 돈이 되는 것은 다르다.** 적중률이 아니라 기대값과 회수율을 봐야 합니다.
- **기록은 전부 공개해야 의미가 있다.** 잘 된 경주만 보여주면 누구나 고수처럼 보입니다. 가치마의 성적 화면에는 맞힌 것과 틀린 것이 모두 남습니다.

앞으로는 모의 장부 300건을 채워서 ★ 규칙이 출발 전 배당에서도 통하는지 확인하고, 서버를 클라우드로 옮길 계획입니다. 결과가 좋든 나쁘든 성적 화면에 그대로 올리겠습니다.

> 가치마는 참고용 분석입니다. 적중이나 수익을 보장하지 않으며, 마권 구매의 판단과 책임은 이용자에게 있습니다.

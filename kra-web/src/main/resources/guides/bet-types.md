# 7가지 승식

| 승식 | 맞혀야 하는 것 | 예 (1착 5번, 2착 2번, 3착 7번) |
|---|---|---|
| 단승 | 1착 한 마리 | 5 |
| 연승 | 고른 말이 3착 안 (7두 이하면 2착 안) | 5, 2, 7 중 하나 |
| 복승 | 1·2착 두 마리, 순서 상관없음 | 5-2 |
| 쌍승 | 1착→2착 순서까지 | 5→2 |
| 복연승 | 고른 두 마리가 모두 3착 안 | 5-2, 5-7, 2-7 |
| 삼복승 | 1~3착 세 마리, 순서 상관없음 | 5-2-7 |
| 삼쌍승 | 1→2→3착 순서까지 | 5→2→7 |

아래로 갈수록 맞히기 어렵고 배당이 커지지만, [공제율](/guide/odds-and-takeout)도 커서(단승·연승 약 20%, 나머지 약 27%) 평균적으로는 더 불리합니다.

# 조합 확률은 어떻게 계산하나

가치마의 승식별 추천은 각 말의 우승 확률에서 조합 확률을 계산합니다(Harville 방식). 예를 들어 A의 우승 확률이 30%, B가 20%라면 "A 1착 다음 B 2착" 확률은 30% × (20% ÷ 70%) ≈ 8.6%로 봅니다. A가 빠진 나머지 70% 안에서 B가 이길 비율을 쓰는 것입니다. 실제로는 2·3착 경쟁이 1착과 조금 다르게 움직여서, 이 값은 근사치입니다.

# 1·2·3위를 그대로 사면?

가치마는 학습에 쓰지 않은 2025~2026년 서울·부경·제주 **3,969경주**로, 당일 분석 1·2·3위를 승식마다 그대로 샀을 때를 검증했습니다.

| 승식 | 산 조합 | 적중률 | 회수율 |
|---|---|---|---|
| 단승 | 1위 | 37.1% | 83% |
| 복승 | 1·2위 | 17.8% | 83% |
| 쌍승 | 1위→2위 | 10.5% | 78% |
| 삼복승 | 1·2·3위 | 10.7% | 80% |
| 삼쌍승 | 1위→2위→3위 | 2.9% | 68% |

![당일 1·2·3위(파랑)와 배당 인기 1·2·3위(회색)를 그대로 샀을 때](/guide-img/pool-roi.png)

**모든 승식이 100%에 못 미쳤습니다.** 1·2·3위는 대체로 배당 인기순과 비슷해서, 그대로 사면 공제율만큼 손해를 보게 됩니다. 가치마가 순위가 아니라 [기대값](/guide/expected-value)이 1.1 이상인 ★ 만 기록하는 이유입니다. 이 표는 성적 화면의 "승식별 회수율"에서 실제 경주 결과로 계속 갱신됩니다.

삼복승·삼쌍승에서는 가치마 순위가 인기순보다 7~11%p 나았지만, 여전히 본전에는 못 미칩니다. 조합이 많은 승식은 공제율이 커서 출발선부터 불리하기 때문입니다.

# 승식별 추천의 '가치 배당'

![당일 분석의 승식별 추천 칸. 노란 줄이 이 경주에 맞는 승식입니다 (예시 숫자)](/guide-img/picks-table.png)

단승 외 승식은 경주 전 조합 배당을 알기 어려워서, 가치마는 기대값 대신 **가치 배당 = 1.1 ÷ 맞을 확률**을 보여줍니다. 예를 들어 복연승 3-10의 맞을 확률이 24%라면 가치 배당은 4.6배이고, 실제 배당이 이보다 높을 때만 기대값 1.1을 넘습니다.

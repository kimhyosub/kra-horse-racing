가치마모델 가중치
경주 성적 가중치
가중치 읽는 법 요인 값은 같은 경주 출전마끼리 평균 0, 표준편차 1로 맞춘 뒤 가중치를 곱합니다. 그래서 가중치 숫자 크기끼리 바로 비교할 수 있습니다. + 이면 값이 클수록, − 이면 값이 작을수록 우승 확률을 올립니다. "무엇이 유리한가" 칸에 말로 풀어 두었습니다. 예/아니오 요인(데뷔전, 기수 교체 등)은 해당할 때 그만큼 더해집니다. 막대 = 가중치 크기(부호 무관). 묶음 비율 = 그 묶음 가중치 크기 합이 전체에서 차지하는 비율로, 모델이 어디를 많이 보는지 대략 알 수 있습니다.
